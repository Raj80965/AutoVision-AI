📌 About Project

AutoVision AI is a state-of-the-art autonomous driving system built on CARLA Simulator, YOLOv8, OpenCV, PyTorch, and Flask. It perceives vehicles, pedestrians, traffic signs, and road boundaries in real-time, then fuses sensor data to generate intelligent driving commands — steering, throttle, and braking. The hybrid AI pipeline combines computer vision with decision planning, achieving robust autonomous navigation in complex urban scenarios.

⚙️ Project Workflow

  1. 📸 Camera captures real-time environment frames.
  2. 🎯 YOLOv8 detects vehicles, pedestrians, traffic lights.
  3. 📊 AI analyzes traffic density & obstacle trajectories.
  4. 🧠 Decision engine computes steering, throttle, brake commands.
  5. 🚗 Vehicle navigates autonomously inside CARLA Simulator.
  6. 📡 Flask dashboard visualizes telemetry and detection overlay.
