📌 About Project

AutoVision AI is an advanced autonomous driving system developed using CARLA Simulator, YOLOv8, OpenCV, PyTorch and Flask. The system can detect vehicles, pedestrians, traffic signs and road conditions in real-time, analyze the environment and generate intelligent driving decisions automatically.

🚀 Key Features

✅ Real-Time Object Detection
✅ Traffic Light Recognition
✅ Vehicle Tracking
✅ Obstacle Detection
✅ Lane Detection
✅ Path Planning
✅ Automatic Emergency Braking
✅ AI Decision Making

⚙️ Project Workflow

  1. Camera captures real-time environment.
  2. YOLOv8 detects vehicles, pedestrians and traffic lights.
  3. AI analyzes traffic conditions.
  4. Decision engine generates steering, throttle and brake commands.
  5. Vehicle moves autonomously inside CARLA Simulator.
