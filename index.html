📌 About Project

AutoVision AI is an advanced autonomous driving system built on CARLA Simulator, YOLOv8, OpenCV, PyTorch, and Flask. It fuses computer vision and sensor data to detect vehicles, pedestrians, traffic signs, and road boundaries in real-time. The AI decision engine, powered by hybrid behavioral cloning & rule-based safety, generates smooth steering, throttle, and braking commands — bridging the gap between research-grade autonomy and real-world simulation.


Production-ready pipeline | ROS-like architecture

⚙️ Execution Pipeline

  1. 🌍 CARLA world spawns ego-vehicle with RGB & semantic cameras.
  2. 📸 Real-time frames processed via YOLOv8 (detection + classification).
  3. 🧩 DeepSORT tracker maintains object IDs and velocity vectors.
  4. 🧠 AI fusion module predicts future trajectories & risk assessment.
  5. 🕹️ Decision engine computes low-level control commands (throttle/steer/brake).
  6. 📡 Flask server streams telemetry & bird's-eye view to web dashboard.
  7. 🔄 Continuous closed-loop optimization with performance metrics.
