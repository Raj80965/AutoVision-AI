Perceive • Predict • Drive

📌 About Project

AutoVision AI is an Autonomous Driving System developed using CARLA Simulator, YOLOv8, OpenCV, Flask and Python. The system detects vehicles, pedestrians, traffic signs and road conditions in real-time and makes intelligent driving decisions.

🚀 Key Features

  • YOLOv8 Real-Time Object Detection
  • Traffic Sign Recognition
  • Obstacle Detection
  • Lane Detection
  • Vehicle Tracking
  • Automatic Emergency Braking (AEB)
  • Path Planning
  • AI Driving Decisions
  • CARLA Simulation Environment

🛠 Technologies Used

Python
YOLOv8
OpenCV
CARLA Simulator
Flask
NumPy
PyTorch
Computer Vision

🏗 System Architecture

Camera → YOLO Detection → Object Tracking → Decision Making → Vehicle Control

CARLA Sensors → AI Processing → Path Planning → Steering / Brake / Throttle

📊 Project Workflow

  1. Camera captures live environment.
  2. YOLOv8 detects vehicles, pedestrians and traffic lights.
  3. AI analyzes road conditions.
  4. Decision engine generates driving commands.
  5. CARLA vehicle executes steering, throttle and braking.
